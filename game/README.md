# 게임 서버

`home.html`에서 실행하는 LAN 아레나, 포트리스, 웨이브 디펜스, 파티 게임, 싱글 RPG의 정적 파일 및 HTTP/WebSocket 서버입니다.

## 실행

호스트 PC에서 서버를 실행합니다.

```bash
python game/server.py --host 0.0.0.0 --port 7000
```

호스트는 브라우저에서 아래 주소를 엽니다.

```text
http://localhost:7000/
```

같은 LAN의 다른 사용자는 호스트 PC의 IP로 접속합니다.

```text
http://HOST_IP:7000/
```

LAN 아레나는 `/ws`, 포트리스 멀티 모드는 `/fortress`, 웨이브 디펜스 멀티 모드는 `/defense`, 파티 게임은 `/party` WebSocket을 사용합니다. 통합 입장 센터에서 만든 게임 방은 `room` query로 분리되며, 예를 들어 `/ws?room=ABCDE`, `/fortress?role=client&room=ABCDE`, `/fortress?role=spectator&room=ABCDE`, `/defense?room=ABCDE`, `/party?game=kart&room=ABCDE`처럼 접속합니다. 방화벽에서 TCP `7000` 포트가 허용되어야 다른 PC가 접속할 수 있습니다.

포트리스 멀티는 방마다 P1/P2 두 명이 플레이하고, 3번째 이후 접속자는 관전자로 들어갑니다. 관전자는 화면에 관전 상태가 표시되고 조작할 수 없으며, 플레이어가 나가면 오래된 관전자부터 자동으로 빈 슬롯에 참여합니다.

`포트리스 혼자하기`는 WebSocket 서버 없이 브라우저 안에서 로컬로 실행됩니다. 각 턴에는 이동 게이지가 130 지급되고, 파워는 30~170 범위에서 조절하며 기본값은 넓어진 전장에 맞춘 145입니다. `Z/X/C/V/B`로 표준탄, 강타탄, 광역탄, 분열탄, 굴착탄을 선택합니다. 포트리스 화면은 독자 레트로 차량, 지형, HUD, 폭발 효과를 Canvas/CSS로 그리며 원작 게임 자산을 사용하지 않습니다.

## LAN connection note

- `127.0.0.1`, `127.x.x.x`, and `localhost` always mean the current PC only.
- If the host PC is `192.168.1.154` and the active game port is `7000`, other PCs should open `http://192.168.1.154:7000/game/index.html`.
- Arena can also use `http://192.168.1.154:7000/game/index.html?host=192.168.1.154&port=7000&room=ABCDE&auto=1`.
- Fortress multiplayer join uses `http://192.168.1.154:7000/game/index.html?game=fortress&mode=multi&role=client&host=192.168.1.154&port=7000&room=ABCDE`.
- Party games use `http://192.168.1.154:7000/game/index.html?game=kart&mode=multi&host=192.168.1.154&port=7000&room=ABCDE&auto=1`. Replace `kart` with `bomb`, `snake`, or `coin`.
- The game screen has a collapsible connection info panel. `현재 화면` is the local page currently open, `서버 연결` is the WebSocket target used by the game, and `초대 링크` is the address to send to another participant.
- The Windows launcher may use `7001`, `7002`, and so on if `7000` is busy. Use the port shown in the dashboard or in the in-game connection panel.

## Hub socket

The server also exposes `/hub` for the unified entry center and Share&Drop. It reuses the same HTTP/WebSocket port as the games, so no extra socket port is required. The unified entry center uses `/hub` to list and create game rooms, while Share&Drop uses `/hub` rooms for chat and file transfer. Share&Drop relays file chunks between browsers in the same room and currently limits each file to 100MB.

## 웨이브 디펜스

웨이브 디펜스 멀티는 `/defense?room=ABCDE` WebSocket을 사용합니다. 통합 입장 센터의 `defense` 방에서 바로 입장할 수 있고, 첫 접속자가 방장이 되어 첫 웨이브를 시작합니다. 참가자는 각자 개인 자원으로 기본탄, 감속, 폭발, 저격, 증폭기 타워를 배치하며, 기본 우회로/항구 지그재그/용암 협곡 맵에서 15웨이브 동안 기지를 지키면 승리합니다. 방장은 전투 중 1배/2배/3배속을 선택할 수 있고, 로컬 솔로와 멀티 서버 모두 같은 속도 규칙을 사용합니다. 폭발 타워는 화상을 남겨 지속 피해를 주고, 저격 타워는 취약 표식으로 후속 피해를 키웁니다. 5/10/15웨이브에는 보스가 등장하고, 첫 웨이브 이후에는 준비 시간이 끝나면 다음 웨이브가 자동으로 시작됩니다.

멀티 타워는 소유자 색상 링과 이름표를 전장에 표시합니다. 내 타워는 노란 `나` 배지, 다른 참가자 타워는 참가자 이름 머리글자로 구분하고, 참가자 목록에는 개인 자원, 타워 수, 처치 수를 함께 보여 줍니다. 하단 타워/전술 패널은 요약 헤더와 접기 버튼을 제공하며, 좁거나 낮은 화면에서는 버튼 설명을 줄이고 전장 카메라 스케일을 패널이 덜 가리는 영역에 맞춥니다.

타워 디자인은 타입과 업그레이드 단계에 따라 달라집니다. 기본탄은 쌍포신, 감속은 결정형 냉각 장치, 폭발은 박격포형 포구, 저격은 긴 포신과 조준경, 증폭기는 다중 에너지 링으로 그려지고, 업그레이드 단계는 본체 크기와 하단 단계 표시로 확인할 수 있습니다.

혼자하기는 `game/index.html?game=defense&mode=solo`로 실행되며 WebSocket 서버 없이 브라우저 또는 EXE 안에서 동작합니다.

## 카트 랠리와 파티 게임

카트 랠리와 파티 게임 3종은 공통 `/party?game=TYPE&room=ABCDE` WebSocket을 사용합니다. 지원 타입은 `kart`, `bomb`, `snake`, `coin`입니다.

- `kart`: 체크포인트 3바퀴 완주 레이싱입니다. Space를 누른 채 코너를 돌면 드리프트를 충전하고, 키를 떼면 미니부스터를 사용하며 부스터 패드, 니트로 픽업, 드래프트, 오일 트랩으로 추월합니다.
- `bomb`: 폭탄을 설치하고 블록을 부숴 화력/폭탄수/속도/킥/원격 기폭 파워업을 모으며, 연쇄폭발 범위를 피해 점수를 얻습니다.
- `snake`: 먹이를 모아 길어지고 실드/보너스 먹이/사냥 모드로 벽과 꼬리 충돌 위기를 넘깁니다.
- `coin`: 움직이는 위험 구역을 피해 콤보, 자석, 피버 보너스로 코인과 보석을 모으고 은행/금고에서 점수를 현금화하는 시간제 점수 경쟁입니다.

각 게임은 `game/index.html?game=TYPE&mode=solo` 혼자하기 폴백을 제공하고, 멀티 화면에는 `?` 도움말과 `i` 접속 정보 패널이 있습니다. 라운드는 제한 시간 또는 완주 조건으로 종료되고 승자를 표시하며, 작은 화면에서는 터치 방향 패드와 액션 버튼으로 조작할 수 있습니다.

## 서약의 연대기 RPG

서약의 연대기는 `game/index.html?game=rpg&mode=solo`로 실행하는 소켓 없는 싱글 플레이 RPG입니다. 게임 화면에서 WASD/방향키 이동, `J` 기본 공격, NPC 앞 `Space` 또는 `E` 말풍선 대화/상점/포털/채집/야영, `K/2/3/4` 서약 전술, `O` 동료, `X` NPC 인연, `R` 성소 재건, `C` 서약 공방, `Z` 연금과 야영식, `F` 현상수배, `Y` 서약 각인, `V` 지역 연대기, `T` 칭호, `전술`/`계획`/`강적`/`야영`/`순찰`/`장비록`/`원정`/`보물`/`유물`/`회상전` 버튼, `Shift` 회피 대시, `1` 회복약, `Ctrl+S` 저장을 사용합니다. 좌측 상태, 우측 정보, 하단 조작 패널은 각 패널의 접기 버튼으로 접었다 펼 수 있고 접힘 상태는 실행 환경에 저장됩니다.

우측 정보 패널 상단의 `다음 행동` 영역은 가까운 상호작용, 메인 목표, 체력 경고, 성장 포인트, 비어 있는 장비 슬롯, 착용 대비 좋은 장비 후보, 현재 지역 미획득 고유 장비, 장착 가능한 각인, 보스전 음식/영약 준비, 바로 보고 가능한 순찰/장비록/전술 교범/원정/감사장 항목을 우선 표시합니다. 각 항목의 버튼으로 상호작용 진행, 회복약 사용, 상점/가방/성장/각인/연금/도감/관련 메뉴 열기, 퀘스트 지역 이동을 바로 실행할 수 있고, 진행 수치 그리드는 스크롤 영역으로 제한해 긴 장기 콘텐츠 목록이 현재 목표와 상호작용 안내를 밀어내지 않도록 구성했습니다. 가방의 무기/방어구/부적은 강화, 숙련, 희귀도, 세트 여부, 전투/보상 옵션을 합산한 장비 평가와 착용 대비 차이를 함께 보여 줍니다. 몬스터 도감은 고유 장비별 획득/미획득 상태와 일반/보스 드롭 기대 확률을 함께 보여 줘 몬스터별 장비 파밍 목표를 추적할 수 있습니다.

폭탄 그리드는 로컬 솔로와 `/party` 멀티 모두 파괴 가능한 블록을 사용합니다. 폭탄 십자 폭발이 닿은 블록은 사라지고, 일부 블록은 코인/부스터/화력/추가 폭탄/속도 파워업을 드롭해 플레이어가 전장을 직접 개척할 수 있습니다.

폭탄 그리드 폭발 범위 안의 다른 폭탄은 연쇄폭발로 이어집니다. 플레이어 상태에는 `bombPower`와 `bombLimit`이 포함되며, 로컬 솔로와 멀티 서버가 같은 폭탄 최대 설치 수와 폭발 반경 계산을 사용합니다.

폭탄 그리드는 킥 파워업을 먹으면 제한 시간 동안 폭탄을 이동 방향으로 밀 수 있습니다. 이동 중인 폭탄은 `vx`/`vy` 상태를 공유하고, 벽/파괴 가능한 블록/다른 폭탄에 닿으면 멈추므로 로컬 솔로와 `/party` 멀티가 같은 전장 조작 규칙을 사용합니다.

폭탄 그리드는 원격 기폭 파워업을 먹으면 폭탄 한도에 도달한 상태에서 Space로 가장 오래된 내 폭탄을 즉시 터뜨릴 수 있습니다. 플레이어 상태에는 `bombRemote`가 포함되고, 로컬 솔로와 `/party` 멀티 모두 원격 픽업, 즉시 기폭 이펙트, 점수판 보유 수 표시를 사용합니다.

폭탄 그리드는 로컬 솔로와 `/party` 멀티 모두 폭탄 폭발 전 십자 범위를 위험 타일과 점선 경로로 예고합니다. 폭발 시간이 가까워질수록 경고가 강해지고, 폭발 범위의 블록은 붉은 균열 표시가 생겨 다음에 열릴 길을 미리 읽을 수 있습니다.

스네이크 배틀은 Space 순간 질주, 역주행 제한, 부스터/보석/실드/보너스 먹이를 사용합니다. 실드가 켜진 동안 벽 또는 꼬리에 닿으면 실드를 소비하고 한 번 살아남으며, 꼬리를 짧게 정리해 재진입할 수 있습니다. 코인 러시는 보석, 실드, 자석, 피버 픽업을 사용하며, 실드가 켜진 동안 위험 구역에 닿으면 실드를 소비하고 한 번 살아남습니다.

스네이크 배틀의 희귀 보너스 먹이 `feast`는 큰 점수와 짧은 질주 보너스를 제공합니다. 로컬 솔로와 `/party` 멀티 모두 같은 픽업 분포, 실드 방어, 보너스 먹이 이펙트를 사용합니다.

스네이크 배틀은 `feast`를 먹으면 짧은 사냥 모드에 들어갑니다. 사냥 모드 동안 이동 속도가 조금 오르고 일반 먹이 점수가 추가되며, 플레이어 상태의 `frenzy` 값으로 몸통 잔상, 머리 링, 점수판 지속 시간 표시가 로컬 솔로와 `/party` 멀티에서 함께 동작합니다.

스네이크 배틀은 질주 중 상대 꼬리에 닿으면 꼬리 일부를 잘라 점수를 얻는 절단 규칙을 사용합니다. 잘린 꼬리는 코인/보석 먹이로 전장에 떨어지고, 서버 상태의 `biting` 값으로 머리 이펙트를 표시해 로컬 솔로와 `/party` 멀티의 공격 타이밍을 같은 방식으로 보여줍니다.

스네이크 배틀은 꼬리 좌표를 매 프레임이 아니라 일정 거리 이동 단위로 기록하고, 시작/리스폰 직후 1.5초 안전시간을 둡니다. 고주사율 브라우저나 EXE 환경에서도 자기 머리 바로 뒤의 촘촘한 좌표가 꼬리 충돌로 잡히는 상황을 줄이며, 멀티 서버도 같은 판정을 사용합니다.

코인 러시는 로컬 솔로와 `/party` 멀티 모두 `combo`, `magnet`, `frenzy` 상태를 사용합니다. 짧은 시간 안에 연속 수집하면 콤보 보너스가 붙고, 자석은 주변 코인/보석을 끌어오며, 피버는 획득 점수를 짧게 2배로 올립니다.

코인 러시는 활성 은행 존에 3콤보 이상 또는 피버 상태로 들어가면 콤보를 보너스 점수로 현금화합니다. 은행 존은 전장과 미니맵에 표시되고, 로컬 솔로와 `/party` 멀티 모두 `banks`와 `bankCooldown` 상태를 공유해 같은 캐시아웃 타이밍을 사용합니다.

코인 러시에는 더 높은 보상을 주는 금고 존이 함께 등장합니다. 금고는 6콤보 이상 또는 피버 상태에서만 열리고 일반 은행보다 큰 보너스와 긴 재사용 대기 시간을 가지며, `banks` 상태의 `kind: "vault"`로 전장과 미니맵에서 보라색 목표 지점으로 표시됩니다.

코인 러시는 로컬 솔로와 `/party` 멀티 모두 위험 구역 텔레그래프, 콤보 수집 후보 링, 은행/금고 현금화 경로, 자석 연결선을 전장에 표시합니다. 점선 화살표와 `현금화 가능`/`금고 가능` 라벨로 넓은 맵에서도 다음 목표를 빠르게 판단할 수 있습니다.

카트 랠리는 로컬 솔로와 `/party` 멀티 모두 드리프트 충전과 미니부스터 상태를 사용합니다. 드리프트 중에는 차량 뒤쪽에 스모크/스파크가 표시되고, 충전 후 키를 떼면 짧은 미니부스터 이펙트가 발생합니다.

카트 랠리 트랙에는 로컬 솔로와 `/party` 멀티 모두 `boostPads`가 표시됩니다. 패드를 밟으면 짧은 부스터와 점수 보너스를 얻고, 니트로 픽업은 일반 부스터보다 긴 가속을 제공합니다. 부스터 패드는 전장과 미니맵에 함께 표시됩니다.

카트 랠리는 앞차 뒤 같은 방향으로 붙어 달리면 드래프트가 충전됩니다. `draftCharge`가 가득 차면 짧은 추월 부스트와 점수 보너스가 발동하며, 로컬 솔로와 `/party` 멀티 모두 같은 거리/방향 판정과 공기 흐름 이펙트를 사용합니다.

카트 랠리는 오일 픽업을 먹으면 뒤쪽에 오일 장판을 남깁니다. 다른 카트가 장판을 밟으면 짧게 회전하며 감속하고 드래프트/드리프트 흐름이 끊깁니다. 로컬 솔로와 `/party` 멀티 모두 `oilSpin`과 `hazards` 상태를 사용하고, 전장/미니맵/점수판/이펙트 텍스트로 오일 트랩과 미끄러짐 상태를 표시합니다.
