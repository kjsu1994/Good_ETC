LAN 아레나

호스트 PC에서 python game/server.py --host 0.0.0.0 --port 7000을 실행한 뒤, 같은 LAN 사용자는 호스트 IP와 포트로 접속합니다.
브라우저 보안상 home.html은 방화벽을 직접 변경할 수 없습니다. 아래 입력값으로 생성한 bat 내용을 관리자 권한으로 실행하세요.
호스트 IP
게임 포트
허용할 원격 IP
방화벽 규칙명
서버 실행 후 방화벽에서 TCP 7000 포트를 허용해야 LAN 접속이 가능합니다.
